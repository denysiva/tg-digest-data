# 📝 КРОК 4 — EXPAND «Також у дайджесті» 11-30 (КРИТИЧНИЙ)

**Це головна додаткова цінність Routine 2.** Routine 1 пише items 11-30 як 1 dense paragraph each. Routine 2 expand-ить кожен у 3 коротких блоки.

## 4.1. Target structure для кожного item 11-30

```markdown
### {N}. {Headline — main point простою мовою, не назва теми}

**Контекст.** 1-2 речення про автора/джерело + чому це важливо. Якщо актор не очевидний — короткий bio. Прибрати jargon, замінити на принцип.

**Що сталось.** 2-3 речення з конкретикою. Хто/що/коли/де. Якщо є цифри — у тексті або у bullet list (max 3 bullets).

**Що робити.** 1-2 речення з role tag як `*italic*`:
- `*Senior buyers*` — конкретна дія
- `*Тімлідам*` — конкретна дія
- `*Operations*` — конкретна дія

**Джерело.** [Лінк](url)
```

## 4.2. Style guide для expand

- **НЕ роздувай штучно.** Якщо в original 1 paragraph було 4 речень → expand до ~6-8 речень (структуровано), не 12.
- **Зберігай factual core.** Усі цифри / GEO / бренди з original — preserve у expanded version.
- **Glossary discipline** — терміни з чорного списку пояснюй у дужках при першій згадці у item.
- **Active voice** — «команда запустила» > «було запущено».
- **Quote handling** — якщо у original є quote, переклади на UA з marker.
- **NO new facts** — не вигадуй цифр/деталей яких не було у original.

## 4.3. Якщо «Також» < 18 items

Не вигадуй. Просто expand-и скільки є. Footer у Slack/Notion відобразить реальну кількість.

## 4.4. Якщо item — це короткий update без actionable

Залиш як 2-block (Контекст + Що сталось) без «Що робити».
